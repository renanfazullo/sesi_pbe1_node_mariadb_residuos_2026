
# Gestão de Resíduos

## Descrição

Sistema desenvolvido para a Prefeitura de Amparo, com o objetivo de monitorar pontos de descarte irregular de lixo, entulho e resíduos eletrônicos.

## Tecnologias

- Node.js
- Express
- MariaDB
- MySQL2
- JavaScript
- Insomnia
- Git e GitHub

## Diagrama de Classes

![Diagrama de Classes](./backend_residuos/docs/der_residuos.png)

## Funcionalidades

- RF001: CRUD de usuários.
- RF002: Login.
- RF003: CRUD de ocorrências de resíduos.
- RF004: Contagem total de ocorrências tratadas.
